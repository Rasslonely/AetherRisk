Create `app/api/proof/route.ts` implementing `POST /api/proof`:
- Accepts request body `{ txHash: string; chainKey?: number; forceLayer?: string }`.
- Searches `prisma.cachedProof.findUnique({ where: { txHash } })`.
- If found, returns cached Merkle root, siblings, and continuity digests with `source: 'CACHED_REAL_PROOF'`.
- If not in DB, searches `PRESEEDED_OPERATIONS` matching `sourceTxHash` or `creditcoinTxHash`.
- If not found in preseeded records, generates a deterministic valid inclusion proof structure matching precompile `0xFD2` specifications with `source: 'SANDBOX_SIMULATION'`.
- Returns `{ success: true, source: ProofSource, latencyMs: number, generatedAt: string, data: AttestcoinProofPayload }`.
